# How to Join
### Step One
Download the correct version of [Prism Launcher](https://prismlauncher.org/download) for your machine.

Install it as you'd install any other application.

### Step Two
Go to the [github repo](https://github.com/E3DD-1213/Minecraft-Server) and download the latest Release from the right panel.

### Step Three
Launch Prism Launcher. Click "Add Instance" in the top left corner and select "Import" from the list of options on the left. 

### Step Four
Navigate to the .zip file you downloaded in step two and select it. 

Name the instance however you want then press "OK".

### Step Five
Log into Prism Launcher with your Minecraft/Microsoft account details.

### Step Six
Get the IP from Eric and give him your Minecraft username to whitelist.

### Step Seven
Add the server under multiplayer and have fun!
